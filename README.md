# CPPG 기출 마스터

개인정보관리사(CPPG) 문제집 PDF를 불러와 브라우저에서 기출을 풀어 보는 사이트입니다.
정보보안기사 실기용 [gichul-study](https://github.com/lshysh626/gichul-study)(IS MASTER)의 화면 구성과 테마를 따랐습니다.

**사이트:** https://cppg.songcoco.kr

> **문제 데이터는 이 저장소와 사이트에 들어 있지 않습니다.**
> 문제집은 저작권이 있는 유료 자료입니다. 직접 구매한 PDF를 사이트에서 불러오면
> 브라우저 안에서만 분석해 그 기기(IndexedDB)에 저장합니다. 파일은 어디에도 업로드되지 않습니다.

## 다른 기기에서 쓰기

PDF를 불러온 기기에서 **설정 → 다른 기기에서 쓰기**로 비밀번호를 정하면, 브라우저 안에서
AES-256-GCM(PBKDF2-SHA256 150만 회)으로 암호화한 `cppg.enc`가 만들어집니다.
이 파일을 `library/cppg.enc`로 올리면 다른 PC·폰에서는 비밀번호만으로 같은 자료를 엽니다.
저장소에는 암호문만 있고, 비밀번호는 어디에도 저장되지 않습니다.

## 기능

- **세 가지 모드**: 즉시 채점 / 실전 모드(다 풀고 한 번에 채점) / 학습 모드(정답·해설 먼저 보기)
- **실전 모의고사**: 300제에서 과목 비율(10·20·25·30·15)대로 100문항 랜덤 출제, 120분 타이머, 과목별 40%·총점 60% 합격 판정
- **회차별 풀기**, **과목별 풀기**(랜덤 20 / 전체 / 안 푼 문제)
- **다시 볼 문제**: 폴더·하위 폴더로 북마크 정리, 여러 폴더를 골라 섞어 풀기, 틀린 문제 자동 모음
- **원본 보기**: 표·그림 문제는 저장된 PDF 페이지를 바로 렌더링 (휠 확대, 드래그 이동)
- **채점 결과**: 과목별 정답률·과락, 문항별 O/X, 전체 해설 검토, 오답만 다시 풀기
- **학습 통계**, 풀던 문제 이어서 풀기, 기록 내보내기/가져오기
- 단축키: `1`~`5` 선택, `Ctrl+[` 이전, `Ctrl+]` 다음, `Ctrl+Enter` 다음·제출, `B` 다시 볼 문제, `Esc` 문항표

## 구조

```
index.html       화면 틀
style.css        IS MASTER 다크 테마
js/parser.js     PDF → 문제 데이터 (PDF.js 그리기 명령에서 텍스트 재구성)
js/db.js         IndexedDB 저장소
js/vault.js      문제집 암호화/복호화
vendor/pdfjs/    PDF.js 3.4.120 (Apache-2.0)
library/         암호화된 문제집 (cppg.enc)
js/app.js        화면·풀이·채점·폴더·통계
```

개발 과정은 [docs/DEVLOG.md](docs/DEVLOG.md)에 정리했습니다.

빌드 과정 없이 정적 파일 그대로 GitHub Pages에 배포됩니다. 로컬에서 확인하려면:

```bash
python -m http.server 8000

```
