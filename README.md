# CPPG 기출 풀이

개인정보관리사(CPPG) 문제집 PDF를 불러와 브라우저에서 기출을 풀어 볼 수 있는 사이트입니다.

> **문제 데이터는 이 저장소에 포함되어 있지 않습니다.**
> 문제집은 저작권이 있는 유료 자료이므로, 직접 구매한 PDF로 각자 데이터를 생성해 사용하세요.
> 생성된 데이터(`data/`)와 PDF는 `.gitignore`로 제외되어 있습니다.

## 기능

- **실전 모의고사**: 회차별 100문항, 120분 타이머, 제출 후 채점. 과목별 40%·총점 60% 기준으로 합격/과락 판정
- **연습 모드**: 회차·과목·문항 수를 고르고 한 문제씩 풀면서 바로 정답과 해설 확인
- **오답노트**: 틀린 문제가 자동으로 쌓이고, 다시 풀어서 맞히면 빠짐
- **북마크**, **풀이 기록**(내보내기/가져오기)
- 표·그림이 들어간 문제는 **원본 보기**로 PDF 페이지 이미지를 확인
- 키보드 단축키(`1`~`5` 선택, `←` `→` 이동, `B` 북마크), 다크 모드

풀이 기록은 브라우저 `localStorage`에만 저장됩니다.

## 사용법

```bash
pip install pypdf pypdfium2
python scripts/parse_pdf.py <문제집 PDF 경로>
```

그다음 `index.html`을 브라우저로 열면 됩니다. 서버나 빌드는 필요 없습니다.

`parse_pdf.py`는 다음 파일을 생성합니다.

| 파일 | 내용 |
| --- | --- |
| `data/questions.js` | 사이트가 읽는 문제 데이터 (회차, 번호, 과목, 발문, 선지, 정답, 해설) |
| `data/questions.json` | 같은 내용의 JSON |
| `data/pages/*.png` | 원본 페이지 이미지 (`pypdfium2`가 설치된 경우) |

파싱이 어긋난 문항이 있으면 실행 결과에 `확인 필요` 목록으로 표시됩니다.

## 구조

```
index.html          화면 틀
app.js              풀이 로직 (해시 라우팅, 채점, 기록)
style.css           스타일 (라이트/다크)
scripts/parse_pdf.py  PDF → 문제 데이터 변환
```
